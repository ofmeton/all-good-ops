# storm-research — 多視点ペルソナで深掘りする課金ゼロのリサーチ

STORM（stanford-oval, NAACL 2024）の論文メソッドを、Claude のサブスク内サブエージェントで再現する深掘りリサーチ。STORM 本体（litellm で API 従量課金・重い venv）は入れない。**考え方だけ**を借りる。

## いつ使う / deep-research との棲み分け

| | storm-research（本スキル） | deep-research（plugin） |
|---|---|---|
| 向く | 1トピックを**多視点で体系化**した参考記事を1本作る／**自分の構想を多角的に吟味**する | 事実の正確性・A/B比較・最新動向の単発確認 |
| 核 | 視点ペルソナを並列で立て、各々が質問駆動で調査 | fan-out検索→反証検証→引用合成 |
| 出力 | 引用付き長文 Wiki 記事 | 引用付きレポート |

迷ったら deep-research が既定。本スキルは「多視点・記事性・構想の吟味」が要るときに使う。両方とも着地は `outputs/research/`。

## 手順（STORM 5段階の再現）

1. **視点発見**: トピックに対し 3〜5 の異なる視点ペルソナを立てる。汎用セット例 ＝ ①実務家/単位経済 ②先行事例/設計メカニズム ③市場・制度・データ ④批判的リスク/失敗筋道（必要なら ⑤歴史的経緯/初心者）。構想の吟味なら④を必ず入れる。
2. **質問駆動の並列調査**: 視点ごとに `researcher` サブエージェントを**並列起動**（`superpowers:dispatching-parallel-agents`）。各エージェントに「担当視点の問い」＋「対象（構想）コンテキスト」を渡し、WebSearch/WebFetch で深掘りして **出典URL＋信頼性ランク付きの調査メモ＋その視点からの吟味** を返させる。`research-protocol.md` の様式に準拠。
3. **統合アウトライン**: 全視点のメモを集約・重複排除し、記事のセクション構成を組む。
4. **引用付き執筆**: 全出典を通し番号化し、各セクションを `[n]` で引用しながら執筆（root=メインが書く。発信文・吟味は Claude 中核）。
5. **仕上げ**: 要約（エグゼクティブサマリ）を先頭に、末尾に「情報源一覧」（信頼性ランク付き）。構想の吟味なら「次に決めるべき論点」を伴走の問いとして残す。

## 規模プリセット（depth）

- **quick**: 視点2〜3 / 各1〜2ターン（軽く全体像）
- **standard（既定）**: 視点3〜4 / 各2〜3ターン
- **deep**: 視点4〜5 / 各3ターン以上（トークン増）

標準調査の2〜3倍のトークンを食う。重い分、深掘り・吟味が要る局面に限定する。

## 着地と引用

- 成果物: `outputs/research/YYYY-MM-DD-<slug>.md`
- frontmatter に `generator: storm-method` ／使用モデル ／`cost: ¥0` を明記（deep-research/researcher と区別）
- 既存の内部分析があれば出発点として参照し、外部調査と統合する（重複調査を避ける）

## コスト

**¥0。** すべて現セッションのサブスク内サブエージェント。API キー・litellm・claude -p サブプロセス・外部従量 API は使わない → `external-api-cost-disclosure` の対象外。

## 絶対にやらないこと

1. **API/claude -p/従量課金バックエンドを使わない** — 「課金ゼロ」がこのスキルの存在意義。サブスク内サブエージェントのみ。
2. **deep-research と二重起動しない** — 単発の事実確認・比較は deep-research。本スキルは多視点・記事化のときだけ。
3. **引用URLのないファクトを書かない** — 推測は「推測（要確認）」と明記。信頼性ランク（高/中/低）を付ける。
4. **成果物を worktree に埋もれさせない** — main の `outputs/research/` に着地（background 隔離時は worktree で生成後 main へコピー）。ブランチへ混ぜない。
5. **代行で結論を決めない（構想の吟味時）** — 居場所/事業など本人駆動の構想は、判断材料と論点提示に徹し、決定は本人に委ねる（[[feedback_ibasho_user_driven]]）。
