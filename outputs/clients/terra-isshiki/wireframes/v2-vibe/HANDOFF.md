# TERRA HAYAMA — v2-vibe ワイヤーフレーム 引き継ぎ

葉山・一色の一棟貸し（一軒家2階ワンフロア貸し切り）民泊 **TERRA HAYAMA** の、**スクロール演出を主役にした静的ワイヤーフレーム**。動きカタログ（旅館3サイト kikka/shuku/oga 観測）の技法を、静謐・余白のブランドの範囲で適用した提案版。

- **スタック**: Vanilla HTML / CSS / JS の3点 + GSAP ScrollTrigger（ローカル vendoring `assets/vendor/`）。ビルド不要。
- **構成**: 5ページ — `index.html`(TOP) / `rooms.html` / `stay.html` / `access.html` / `owner.html`。共通の `style.css` / `app.js` / `assets/`。
- **位置づけ**: 既存の本番クライアントサイト（`outputs/clients/terra-isshiki/site/`・Next.js）とは別物の、動き主役デザイン版（提案/ポートフォリオ候補）。

## 確認方法

```bash
cd outputs/clients/terra-isshiki/wireframes/v2-vibe
python3 -m http.server 8807
# → http://localhost:8807/index.html
```

演出（オープニング幕・FVの技法E被せ・ピン留め横スクロール）は**素の表示で確認**すること。
**Cue（web-ui-bridge）のオーバーレイ表示中は `body` に transform が掛かり、`position:fixed`/`sticky`/ScrollTrigger pin の基準が壊れる**（オープニングが崩れる・FVヒーローが居座る・ページがスクロールしない、等）。これは Cue 側の既知の制約で、素の表示では正常。Cue編集キュー（`.claude-ui-queue.jsonl`）はリポジトリには含めない（ランタイム生成物）。

## 実装した演出・機能

### FV / オープニング（index TOP）
- **オープニング幕**: 背景は純白、中央に黒ロゴのみ（ナビ・ドックは非表示）。幕がじんわり溶暗（せり上がりなし）しながら、**ロゴが黒→白へ溶ける**（同一要素を `filter:invert()` で。位置不変）。
- **技法E（sticky hero ＋ 被せ）**: 写真ヒーローは固定のまま、paper の被せレイヤー（`.fv-cover` z5・透過・`margin-top:-100svh`）が**波形の上端でせり上がって固定写真を覆う**。波の谷（透過）からは固定写真が透ける。被せ本体（`.fv-cover__pg`）は paper。`.intro` は `350svh`、ink 背景（写真退場後の底を暗くして波カットの土台に）。
- **FV背景スライドショー**: 4枚を時間でクロスフェード（Ken Burns 微ズーム）。
- **コンセプト**: クライアント提供の**原文を厳守**（6連スタンザ構成・指定の改行）。暗い写真の上を透過で流れる没入表示。

### ナビ
- **FV中は完全非表示**（ロゴもメニューもドックも）→ FVを抜けてスクロールすると出現（`body.has-fv` / `.fv-passed`）。下層ページは常時表示。
- メニューは**全幅ハンバーガー集約**（インラインメニュー廃止）。ハンバーガー隣に **JP / EN 切替ボタン**（**見た目のみ・未配線**）。
- ロゴは切り抜きなしのフルロゴ画像。

### セクション共通
- **区切り線（aze）**: 「波打ち際×田んぼの畔」= 茶色の細線＋同形のグレー太線（曲線・塗りなし）の二本構成。`.in` で描画。
- **見出し**: 英字（Rooms/Stay/Access 等）を日本語の**左上アイブロウ**に。サイズは nagare 参照で控えめ（明朝・細）。
- **写真の登場**: 「滲み出る（ぼかし暗→クリア）」で全ページ統一（`emerge`/`emergeF`）。
- **画像内パン視差**: info写真・STAY体験4枚・OWNER写真を1.16倍に拡大し、枠（overflow:hidden）内で translateY パン（`data-paraimg`）。横長画像でも均一に動く方式。

### ROOMS（部屋と空間）
- ピン留め**横スクロール**ギャラリー（PC=GSAP pin、モバイル=scroll-snap carousel フォールバック）。
- **画像クリック → フル表示モーダル**（ライトボックス・`object-fit:contain`・キャプション付き・背景/Escで閉じる）。

### アクセシビリティ / 配慮
- `prefers-reduced-motion` 全面対応（幕・スライド・視差・pin を無効化しフォールバック表示）。

## オープン項目 / 要確認 / 素材待ち

1. **【要目視確認】技法Eの被せの動的タイミング**: headless 環境ではスクロール駆動の検証ができなかった（scroll がスナップして測れず）。静的構造（被せ z5>写真 z1・本体paper・stickyの親 overflow:visible・波が上端）は確認済み。**実機 8807 で被せの上がり具合とコンセプトの収まりを目視確認**すること。
   - 調整ノブ: 被せが早すぎ/遅すぎ → `.fv-cover { margin-top }`（現 `-100svh`）／ コンセプトが詰まる/間延び → `.intro { height }`（現 `350svh`）。
2. **JP / EN 切替**: ボタンは設置済みだが**未配線**（i18n 実装は今後）。
3. **素材待ち（仮画像）**: STAY 02「海越しの富士山」＝ `access-balcony.webp`（仮）、STAY 03「海の幸・山の幸」＝ `hero-03-dining.webp`（仮）。本番写真への差し替え要。キャプションに `※写真は素材待ち（仮）` 明記済み。
4. **CTAリンク**: `href="#"` のプレースホルダ（部屋詳細/予約導線などの遷移先は未設定）。予約は Airbnb 外部リンクのみ実リンク。
