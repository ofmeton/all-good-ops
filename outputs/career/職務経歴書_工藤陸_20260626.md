# 職務経歴書（2026年 06月 26日現在）｜工藤 陸

## 職務要約

Web アプリケーション開発・業務自動化を主軸に、約5年間 IT・デジタルマーケティング領域で業務に従事してきました。

SIer では Python による Web アプリ改修・API 設計・実装・業務自動化に携わり、広告運用のコンサルタントとしては配信データの分析・可視化・改善を主担当として担ってきました。

近年は、Next.js／Supabase を用いた Web アプリケーションの開発・本番運用や、業務自動化パイプラインの構築に取り組んでいます。要件定義・設計から実装・運用保守までを自身で担当し、実装の高速化には AI コーディングエージェントを併用しています。

システム開発の実装力に、広告運用で培ったデータ分析・数値改善の視点を掛け合わせ、AI を活用した開発・業務自動化の即戦力として貢献します。

## 活かせる経験・知識・技術

- Next.js／Supabase を用いた Web アプリケーションの設計・実装・本番運用
- 業務自動化パイプラインの設計（定期実行・失敗時通知・重複防止）、情報収集・SNS 運用の自動化
- Python／GAS／Power Automate による業務自動化の設計・実装
- API 設計・実装、外部サービス連携（LINE／LLM／各種 API）
- 広告配信実績の分析と、入札・クリエイティブ・遷移先の改善（要因分析〜施策実行〜効果検証）
- 週次・月次レポートの作成、データ集計・可視化（Excel／スプレッドシート）
- 検索語句分析、訴求軸抽出、Web アクセス解析と改善提案
